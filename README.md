# Flight Booker

架空の航空券を比較し、条件を満たす最安チケットの予約を競う、PCブラウザ向けの対戦ゲームです。

全員が同じパスポートと条件メモを読み、複数の架空サイトで予約を進めます。安さ、売り切れ、座席確保、価格変動を見ながら判断し、4ラウンドの合計金額を競います。

> 登場する人物・航空会社・予約サイト・便・決済情報は、すべて架空です。空港と都市は実在の名前を使っていますが、実在の空港・航空会社とは関係ありません。実際の予約・決済サービスには接続しません。

## 現在の状態

画面の基本配置（机の上のタブレット、条件メモ、パスポート・カード）、1ラウンドの開始カウント・制限時間、比較サイトでの検索まで実装しています。複数タブや予約サイトは未実装です。

- 初期版：1台のブラウザで、人間1人とNPC（コンピューターが操作する対戦相手）が対戦する。
- 将来：人間同士のオンライン対戦、予約サイトの追加。

実装の順序は[docs/roadmap.md](docs/roadmap.md)にあります。

## ゲームの特徴

- **共通の在庫**：どの予約サイトも同じ座席を売る。他の参加者が買えば、自分の画面の席もなくなる。
- **性格の違う3つの予約サイト**：確定まで席を確保しないサイト、手続きの途中で確保するサイト、閲覧人数で価格が変わるサイト。
- **ゲーム内の複数タブ**：検索を待つ間に、別のタブで他の候補を進められる。
- **誤入力も通る予約**：入力ミスと条件違反は、ラウンド終了時にまとめて判定する。

詳しい仕様は[企画書](docs/flight-booker-game-proposal.md)を参照してください。

## 起動する

Node.js 22系（22.13以降）とnpmが必要です。

```bash
npm ci
npm run dev
```

ターミナルに表示されたURL（標準は <http://127.0.0.1:5173>）をブラウザで開きます。詳しい手順は[docs/getting-started.md](docs/getting-started.md)にあります。

| コマンド          | 内容                                      |

## 使用する技術

| 技術             | 役割                       |
| ---------------- | -------------------------- |
| Vite             | 開発サーバーと配布用ビルド |
| React            | 画面と入力フォーム         |
| TypeScript       | データとゲーム処理         |
| Vitest           | ゲーム処理の自動テスト     |
| ESLint、Prettier | コードの確認と書式の統一   |
| GitHub Actions   | PRと`main`への自動チェック |

画面はReactの部品で構成し、在庫・予約・集計の処理は画面から切り離したTypeScriptで実装します。画面とNPCが同じ処理を通るため、画面を起動せずにテストできます。
