# 環境構築

## 必要なもの

| 道具            | 用途                     | 補足                                              |
| --------------- | ------------------------ | ------------------------------------------------- |
| Git             | 変更履歴の管理           |                                                   |
| Node.js とnpm   | 開発サーバーとツール実行 | 22系の22.13以降。`.nvmrc`とCIも22系               |
| PCのWebブラウザ | 画面の確認               |                                                   |
| GitHub CLI      | PRの作成                 | 任意。GitHubの画面からでも作成できる              |
| エディター      | コードの編集             | VS Codeなら推奨の拡張機能（ESLint、Prettier）あり |

バージョンは次のコマンドで確認できます。

```bash
git --version
node --version
npm --version
```

## 最初の起動

```bash
git clone https://github.com/shakewaka/flight_booker.git
cd flight_booker
npm ci
npm run dev
```

`npm ci`は、`package-lock.json`に記録されたとおりの組み合わせでライブラリを入れます。

ターミナルに表示されたURLをブラウザで開きます。標準は <http://127.0.0.1:5173> です。10秒のカウントの後、机の上にタブレット、条件メモ、パスポートが並んだ画面が表示され、残り時間が減り始めれば成功です。終了するときは、ターミナルで`Ctrl+C`を押します。

## 変更後の確認

```bash
npm run format
npm run check
npm run build
```

| コマンド | 内容                                                               |
| -------- | ------------------------------------------------------------------ |
| `format` | 書式を整える。企画書・画面配置図は対象外             |
| `check`  | ESLintによるコード確認、型の確認、テスト、書式の確認をまとめて行う |
| `build`  | 型を確認し、配布用ファイルを`dist/`に生成する                      |

CIも同じ確認を行います。pushする前に手元で成功させておくと、PRでの手戻りが減ります。

### テスト

```bash
npm test            # 1回だけ実行
npm run test:watch  # ファイルの変更を監視して再実行
```

テストは対象のファイルの隣に`*.test.ts`として置きます。

### ビルド結果を確認する

```bash
npm run preview
```

標準のURLは <http://127.0.0.1:4173> です。ローカルでの確認で、インターネットへは公開されません。

## ライブラリを追加・更新する

```bash
npm install <パッケージ名>       # 画面やゲームの動作に必要なもの
npm install -D <パッケージ名>    # 開発中だけ使うもの
```

`package.json`と`package-lock.json`の両方をコミットします。追加する目的はPRに書きます。

## 環境変数

外部API、データベース、ログインは使用していないため、`.env`ファイルやAPIキーの準備は不要です。

## 困ったとき

| 症状                                           | 対処                                                                                             |
| ---------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| PowerShellで`npm.ps1`を実行できない            | `npm`を`npm.cmd`に置き換える（例：`npm.cmd run dev`）。実行ポリシーを変える必要はない            |
| `npm ci`でNode.jsのバージョンのエラーが出る    | `node --version`を確認し、22.13以降の22系を入れる                                                |
| URLを開いても表示されない                      | ポートが使用中だと番号が変わる。ターミナルに表示されたURLを使う                                  |
| `npm run check`が書式のエラーで失敗する        | `npm run format`を実行してから、もう一度確認する                                                 |
| 依存関係やビルドで原因の分からないエラーが出る | エラー文を記録して原因を調べる。`package-lock.json`の削除や`npm audit fix --force`を先に試さない |
